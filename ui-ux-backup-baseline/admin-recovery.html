How to Promote or Recover Administrator in Firebase

To ensure total application security, OBUMSJ does not permit public client-side self-elevation. Initial administrator access is granted securely in the Firebase Console:

  1. Register or Sign In above using your administrator email address.
  2. Copy your UID shown in the panel above.
  3. Open the Firebase Console > Firestore Database.
  4. Navigate to the users collection and locate the document matching your UID.
  5. Update or add these two fields:
    • Field: role → Type: string → Value: admin
    • Field: status → Type: string → Value: active
  6. Return to this tab and click "Re-check Status from Cloud". You will immediately be granted access to the Dashboard!
Authorized Domain Notice: If testing locally, make sure your domain (e.g. localhost, 127.0.0.1) is listed under Firebase Console > Authentication > Settings > Authorized domains.
